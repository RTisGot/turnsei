# TIDEGLASS ― 潮鏡都市

## Product direction

物語主導の水没都市探索型ターン制RPG。参考作品から採用するのは、未来の行動順を読ませること、共有資源による短い判断、通常時の安定した戦闘構図という設計原則だけとする。固有名詞、キャラクター、画面形状、演出カット、音楽は模倣しない。

## World

海暦217年、半水没都市アステリア。死者の記憶は海中で「潮鏡」として結晶化し、都市の防潮機関はその記憶を燃料として動く。主人公は他人の記憶へ潜れる回収者。第1章では、沈没当日の記録が眠る旧交通層の鐘楼を目指す。

色彩は深い青緑、錆、月光色。現実層は冷色、記憶層は失われた生活を示す暖色にする。

## Vertical slice loop

1. 屋上区画でミオから依頼を受ける。
2. 半水没した旧交通層を探索する。
3. 漂流体と接触し、戦闘へシームレスに遷移する。
4. 通常攻撃で共有APを生成し、技で消費する。
5. 敵の「潮防」を削る。崩壊すると行動が遅れ、次の攻撃が増幅する。
6. 全漂流体を排除し、鐘楼の記憶を回収する。

## Combat readability rules

- 行動選択、ターゲット指定、敵の通常攻撃ではカメラを動かさない。
- 敵味方のワールド座標はターン順に影響されない。
- 左に未来の行動順、左下に味方状態、敵頭上にHP・潮防・潮相、右にコマンドを置く。
- 通常攻撃は短く、技は中尺、必殺だけを専用演出にする。
- 予備動作、接触、フォロースルーを明確に分け、ヒットストップ・VFX・SEのピークを接触へ同期する。

## Next production milestones

### M1: foundation

- `Character*` の所有権を entity ID と `unique_ptr` へ変更
- Ability / Effect / Encounter をJSON化
- Sceneの Enter / Exit / Update / Render とフェードを分離
- セーブ、クエスト、ローカライズ、入力アクションを追加

### M2: battle vertical slice

- 味方3人、敵2種、ボス1種
- 状態異常「浸蝕」、戦場ルール「満潮 / 干潮」
- 攻撃・技・被弾・撃破のAnimationController
- 行動予告、ダメージ予測、必殺割り込み

### M3: drowned district

- 屋上市場、半水没駅、鐘楼の3区画
- 水面反射・屈折、深度色、霧、雨、泡
- 都市プロップのインスタンシング、視錐台カリング、LOD
- 衝突、インタラクション領域、潮位で変化する経路

### M4: narrative

- 分岐会話、条件、フラグ、クエスト、カメラ指示を持つノード形式
- 「鐘楼の記憶」30分章
- ボスをHP撃破または記憶解放で終えられる二重勝利条件
- 選択結果を次章のNPC・地区照明・支援効果へ反映

## Technical risks

現状のCPUスキニングとプロップ個別drawは、高品質モデルと都市規模の背景でボトルネックになる。GPUボーンパレットとインスタンシングを、本格的なアセット投入前に完了させる。既存素材は公開前にライセンスを確認する。
